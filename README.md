## What
This is an interpreter for AS level pseudocode (most of the basic functionality is present-- it is currently being bettered and worked on to include 4-5 remaining things). Haven't really seen other like this, and because I need this to quickly run and validate my thoughts as I write in pseudocode, I made it! (Necessity is the mother of invention or something...)

## How
Main files- 

tokenizer.py

parser.py

interpreter.py

main.py

_any_.pseudo file (you can open a new file, save it with the name followed by .pseudo (example- test.pseudo))

## Why
Me studying in my AS levels wanted an interpreter to write code on and run it. I (quite stupidly) thought this would be a small couple-of-days long project, until it blossomed into something much larger. pseudocode.pro was an option, but also wanted to have the thrill of building my own interpreter...

#### Requirements (also under requirements.txt)
Just have numpy installed for array-handling.
